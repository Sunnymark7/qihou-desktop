# 栖候 0.2.3

## 修复拖动不断放大

在本机 150% 缩放下复现：Electron `setPosition` 连续 20 次，将 360×392 DIP 窗口扩大到 376×411 DIP。仅关闭 thickFrame 无效；每次显式传入尺寸也存在像素舍入。

改为用 Win32 `GetCursorPos` 与 `GetWindowRect` 获取物理像素坐标，以 `SetWindowPos(SWP_NOSIZE | SWP_NOZORDER | SWP_NOACTIVATE | SWP_NOOWNERZORDER)` 仅移动窗口。开始拖动时保存鼠标与窗口起点，过程中绝不把当前尺寸传回尺寸设置接口。

125%、150%、200% 三种缩放配置各运行 500 次移动，原生窗口的宽高保持不变。125% 与 200% 使用 Electron 强制缩放启动参数，150% 为本机实际显示配置。打包应用另外通过渲染器拖动 IPC 注入受控鼠标坐标进行 300 次移动，核对尺寸、最终位置和配置持久化。自动测试不操作用户真实鼠标。

## 桌面与品牌

- 删除桌面上方工具条，不再随悬停出现。
- 桌面天气文字改为纯显示。设置、显示/隐藏等操作保留在托盘；Ctrl+Alt+W 可恢复位置并解除锁定。
- 设置页左上角使用与应用、安装器相同的 ChatGPT 生成图标。

## 天气可读性

- 雨线改为有实际粗细的实例化雨滴，毛毛雨到暴雨按密度、长度、速度递增。
- 雪花使用带淡蓝描边的六角贴图，采用固定屏幕像素尺寸；扬沙继续使用独立颗粒纹理。
- 冰雹增大约 60%，提高反弹幅度；雷雨使用可辨认的闪电面片及缓慢亮灭，暂停/减少动态仍显示静态闪电。
- 雾与沙尘增加低处漂移的半透明雾层；冻雨地面呈冰蓝薄层，晴天太阳带缓慢旋转的光芒。
- 阴天、雨天与雷雨使用不同深浅的云层；云朵始终在建筑后方的天空路径移动。

继续采用实例化粒子和原有质量档位，不引入新运行依赖。天气模型/接口数据语义不变，预览不影响桌面实况。

## 交付

`release-v0.2.3/Qihou-0.2.3-Setup-x64.exe` 为支持自定义安装目录的 NSIS 安装器。安装前从托盘退出旧版；安装后沿用原有设置。旧版异常放大的窗口不会保存到配置中，新版启动会按设置尺寸重新创建。

未完成跨显示器混合 DPI 的实机拖动、长时间运行及实际安装/卸载验证。最终测试与安装包哈希记录在 `docs/evidence/v0.2.3/`。
