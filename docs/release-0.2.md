# 栖候 0.2.2 更新与验证

日期：2026-09-11。沿用 0.1 的 Windows 透明摆件、托盘和实验性壁纸宿主。

## 地标和天气

16 个程序化城市地标：上海东方明珠、广州塔、北京天坛祈年殿、深圳平安金融中心、武汉黄鹤楼、杭州雷峰塔、西安大雁塔、成都安顺廊桥、重庆洪崖洞、天津之眼、苏州东方之门、南京紫峰大厦、郑州中原福塔、青岛五月的风、长沙国际金融中心、厦门世茂海峡双子塔。支持自动按所在地匹配、默认小屋、手动指定地标；指定模型不改变天气地点。均为风格化示意模型。

15 种天气预览：晴、多云、阴、毛毛雨、雨、强降雨、冻雨、雨夹雪、雪、大雪、雾、雷雨、雷雨伴冰雹、雷雪、扬沙。可叠加夜间光照和风力预览。实况按源返回的明确现象渲染，演示不改变桌面的真实天气。

风向袋、树冠摇动、云层移动随风速变化（按用户反馈移除悬浮气流线），风向按来向转换为下风向。雨线按强度增加长度、速度与数量，雨地涟漪更清晰；冰雹采用实例化颗粒，下落后反弹一次；雷电为有轮廓的缓慢亮灭，每 13 秒一个周期，非频闪。减少动态效果会停止连续渲染。

天气源配置和边界见 [api-sources.md](./api-sources.md)。

## 打包和运行优化

- 新增 NSIS 分步安装器，可选择安装目录、当前用户或所有用户，包含快捷方式和卸载入口。用户配置保留在 AppData，与程序目录分离。
- ChatGPT 生成的软件图标覆盖应用、托盘、快捷方式和安装器；提供多尺寸 ICO，高清原稿仅留在源码工作区。
- 桌面整个模型区域可通过指针捕获与主进程鼠标坐标移动，按钮仍可点击；位置通过 move 事件保存。设置预览仍支持旋转模型。
- 云层在独立的后方天空路径漂移，随风力改变速度；开启深度测试保持建筑在云前方，路径两端淡入淡出。
- 仅保留中文和英文 Electron 语言资源。
- 移除重复的 Three.js 源包（渲染所需代码已经打入前端 bundle），移除 Koffi 开发头文件、文档和构建工具，保留实际运行的 JS loader、原生二进制及许可。
- 新增最大压缩 7z、ZIP 分发包；解压后运行完整文件夹，不是把压缩包当成运行目录。
- 节能档：像素比上限 1、无实时阴影、45% 粒子数；均衡档：像素比上限 1.25、512 阴影、70% 粒子；精细档：像素比上限 1.75、1024 阴影、完整粒子。另可选择 15/30/60 FPS 上限。
- 模型切换保留已有天气文字 DOM，修复透明合成截图中偶发的读数消失。

原 0.1 完整目录为 400,063,817 字节（含说明与少量证据图）；0.2 程序主体约 337.6 MB（322 MiB），减小约 15.6%。压缩后的准确字节数、SHA-256 和文件数量在分发目录 `build-size.json` 中记录。压缩比不等于运行内存降低；Electron 仍携带浏览器运行时，没有迁移到系统 WebView2。

- 实际打包应用 smoke：25 项通过，errors 空数组。覆盖所有 16 地标实际绘制及天气读数像素、15 种效果分层、0/3/8/15 m/s 风力、减少动态停止连续帧、紧凑窗口新增各页、托盘、穿透状态、显示/隐藏和壁纸回退。
- Open-Meteo 与 MET Norway 独立实网请求成功。和风及 OpenWeather 因无个人密钥，只做模拟响应与错误处理测试，没有宣称四源均通过实网。
- 最新报告和实际截图在源工作区 `.test-data/`，归档在 `docs/evidence/v0.2.2/`。初次截图测试因窗口被隐藏而等待，后已为截图增加保持隐藏/唤醒选项、超时和总看门狗，完整重跑通过。

`processMetrics` 仅为同时打开设置和摆件时的一次诊断采样；CPU 第一轮采样为零，没有测量意义。不同进程的 working set 可能包含共享页，不相加为独立占用。未进行可对比的 CPU/GPU、运行内存或能耗基准，因此不宣称资源消耗下降百分比。

## 仍有边界

安装器支持选择安装目录及当前用户/所有用户，未做代码签名、Windows 10、多显卡、多屏混合 DPI、Explorer 重启、登录启动、长时间运行和完整故障注入验证。壁纸仍是实验功能。天气是数据源提供的天气模型/当前天气，不是秒级观测；城市搜索不覆盖全部门牌地址。新增模型用于辨认城市轮廓，未达到测绘精度。
