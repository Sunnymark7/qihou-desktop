# 栖候 0.5.0

苹果设计语言启发的 Windows 控制面板：系统字体、蓝色操作色、分组设置、清晰的温度和空气质量曲线。保留 Windows 原生窗口、后台启动和托盘入口，不显示假 macOS 窗口按钮。

首次打开控制面板提供三步引导：选择地点、显示与节能设置、托盘和拖动说明。可跳过、重看，完成状态保存在本机。已有地点的旧版本用户不会被强制重复引导。

内置 54 个城市的约略中心坐标，支持中文、城市后缀、英文和拼音检索；其余地点继续联网搜索，支持手动经纬度。选址后自动匹配地标；已知但没有模型的城市使用小屋，不借用邻近城市建筑。模型库支持筛选。新增哈尔滨圣索菲亚教堂、南昌滕王阁、贵阳甲秀楼、拉萨布达拉宫，共 20 个城市模型。建筑为原创程序化微缩示意，非测绘级复原。

预览支持鼠标直接旋转、释放后惯性、左右方向键和 Home 恢复视角；减少动态效果时禁用惯性。桌面移动继续使用 Win32 物理坐标和保持尺寸的移动方式。

搜索控制器、引导流程、公共转义和新增区域模型独立为模块。静态模型继续按材质合并，未引入外部贴图或模型包。已有激活公钥和配置目录保持一致。

建筑参考：[哈尔滨建筑艺术馆](https://www.ciighrb.com/jtweb/web/culturedetail.do?id=5)、[南昌市政府](https://www.nc.gov.cn/ncszf/rwfg/202505/caef4edf190a44099b002d0891a3d0f8.shtml)、[拉萨市政府](https://www.lasa.gov.cn/lasa/msgj/201706/ea2ee50de05f4c918c4c1c9eba23a6f9.shtml)、[香港特区政府驻成都办贵阳指南](https://www.cdeto.gov.hk/file/pdf/guidegysc2.pdf)。城市目录是本项目维护的近似城市中心选项，天气分辨率由数据源决定。
