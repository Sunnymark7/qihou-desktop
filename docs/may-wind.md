# 青岛「五月的风」模型

用户明确指定替换原青岛教堂，并要求更认真地还原雕塑。模型见 `src/may-wind.ts`，仍使用目录 ID `qingdao`，已保存的青岛选择继续有效。

根据[实物照片](https://commons.wikimedia.org/wiki/File:May_Wind_20090215.jpg)核对轮廓：底部较收束，中部偏上最宽，顶部逐渐收尖；主体为宽扁的红色钢带，切口错位、层间镂空，带有短小阶梯式顶饰和深灰基座。实物参考仅用于观察，没有下载或打包照片。

实现为 11 层带斜向升高的开口环带，分别建立外侧、内侧、上表面和下表面，保留方形截面的硬边；层半径、开口朝向和厚度各自变化。红色漆钢材质有适度反光，暗灰台基承托底部；中央支撑与顶饰保持一致材质。不是用圆管、实心圆锥或贴图代替形体。该模型为程序化形态解释，不是测绘模型或精确复刻。

按用户反馈移除悬浮气流线。风力改由风向袋的方向、下垂程度与抖动，树冠摇动，以及沿下风向缓慢移动的云层表现。所有预览风速设置继续有效。
