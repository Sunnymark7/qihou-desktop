# 栖候 0.3.0

根据 2026-09-11 的设计审查修复五项优先问题。

- 首页缩小 3D 预览，将当前天气、空气指标、温度与空气双曲线放在主要位置。完整模型预览留在“我的场景”。
- 温度曲线使用真实时间横轴和自动数值范围，支持负温及大温差；不再使用封顶的温度细柱。
- 空气质量独立接入 Open-Meteo / Copernicus CAMS，显示 US AQI、PM2.5、PM10。未来 12 小时预报与过去 24 小时本机记录可切换。
- 曲线可悬停读取、使用键盘时间滑块或展开数据表；缺失值、长时间断档和天气来源切换处不连线。
- 本机保留当前地点最近 48 小时已获取记录，按来源数据时间去重；首页展示其中过去 24 小时。首次运行只有已获取点，不补造历史。更换地点清空内存中的旧地点数据，避免串城；不提供多城市历史档案。
- 天气与空气请求独立；空气失败保留缓存并显示错误与时间，不影响天气源切换。暂时只有一个空气质量服务，四个原有天气源保持不变。
- 普通启动进入托盘并按已保存设置显示桌面天气，设置窗口按需调出。打开设置时天气超过 5 分钟未尝试更新则自动刷新；后台约每 15 分钟更新。连续 3D 动画不表示秒级观测。
- 首页与运行页提供真正可开关的桌面显示控制；后台状态、显示模式、开机启动分别说明。全部窗口保持任务栏隐藏。
- 窄窗口逐时预报使用横向滚动，标题标明实际时段数。放大图表刻度，给选中项添加可访问状态，天气预览按天空、降雨、降雪分组。

## 数据说明

空气质量为区域模型估算，非本地监测站实测，也不表示室内空气。US AQI 不等于中国 AQI。污染物浓度单位为 µg/m³。按 API 小时序列展示；底层 CAMS 全球模型按约 45 km 网格、3 小时原始分辨率发布，每 12 小时更新一次，因此每 15 分钟获取并不代表模型每 15 分钟更新。

来源：[Open-Meteo 空气质量文档](https://open-meteo.com/en/docs/air-quality-api)、[Copernicus CAMS](https://atmosphere.copernicus.eu/)。程序界面保留双来源署名。

## 交付与验证

`release-v0.3.0/Qihou-0.3.0-Setup-x64.exe` 支持自定义目录。更新前从托盘退出旧版，配置继续保留。

验证覆盖空气数据解析、缺失值、失败缓存、城市切换竞态、历史持久化、图表交互、宽窄窗口、已有 3D 天气与任务栏回归。最终结果归档于 `docs/evidence/v0.3.0/`。尚未进行实际安装/卸载、跨显示器拖动与长期运行测试。
