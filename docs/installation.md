# 自定义安装

运行 `Qihou-0.4.0-Setup-x64.exe`，按向导选择：

1. 安装给当前用户（默认）或此电脑的所有用户。所有用户模式可能需要管理员权限。
2. 自定义安装文件夹。建议使用一个专门的空文件夹；不要仅把 Qihou.exe 单独复制到别处。
3. 安装完成后可选择运行栖候。程序正常启动进入托盘，并按上次设置显示摆件或壁纸。

安装器创建桌面和开始菜单快捷方式，注册 Windows 卸载项。应用内可单独开启开机启动，安装不会擅自开启它。

更新前从旧版托盘菜单退出栖候。沿用相同 appId 的安装版可升级；旧免安装版文件夹不会被自动删除。位置、天气和密钥设置沿用 `%APPDATA%/Qihou`；卸载默认保留这些数据。

安装目录需要约 330 MiB 可用空间，安装期间另需临时解压空间。安装文件包含程序运行时，无需另外下载 Electron；获取实时天气仍需联网。

当前安装包没有代码签名。Windows 可能显示未验证发布者提示。

## 桌面拖动

未锁定时，按住模型或岛屿拖动即可移动整个摆件，松开后保存位置。桌面没有工具条；设置、显示和隐藏从托盘操作。锁定并穿透鼠标后，从托盘取消锁定，或用 `Ctrl+Alt+W` 恢复编辑。设置窗口内拖动模型仍是旋转视角。

## 图标

安装版采用 ChatGPT 生成的白云、太阳与悬浮岛屿图标，已嵌入可执行文件、安装器及快捷方式。具体提示词和制作记录见 `icon-generation.md`。
