# 栖候 0.2.4

修复打开“天气与设置”后额外显示任务栏图标的问题：公共窗口创建入口统一启用 `skipTaskbar`，覆盖设置窗口首次打开、恢复显示及关闭后重新创建。桌面摆件和壁纸继续不显示任务栏项，设置从托盘调出。

同时修复解除摆件锁定后出现任务栏图标：Electron 44.3.0 的 `setFocusable(true)` 内部会调用 `SetSkipTaskbar(false)`，现在在改变焦点能力后恢复隐藏。所有窗口额外设置原生 `WS_EX_TOOLWINDOW` 并清除 `WS_EX_APPWINDOW`，保留其他样式，使窗口在后续显示和系统重新枚举时也保持工具窗口身份。设置窗口因此也不出现在 Alt+Tab 切换列表，入口统一保留在托盘。

普通启动仍进入托盘，并按保存的偏好显示桌面天气；关闭设置窗口继续后台运行。桌面拖动、天气动画和软件图标沿用 0.2.3。

安装器支持自定义目录，更新前请从托盘退出旧版，再运行 `Qihou-0.2.4-Setup-x64.exe`。已固定在 Windows 任务栏上的旧快捷方式属于用户固定项，需要手动取消固定。

验证会读取 Windows 原生扩展窗口样式，检查 `WS_EX_TOOLWINDOW` 与 `WS_EX_APPWINDOW`，覆盖启动、锁定/解锁、显示恢复、设置重建及壁纸模式。结果保存在 `docs/evidence/v0.2.4/`。实际安装/卸载尚未实机验证。
