# 栖候 0.4.0

天气摆件扩展为天气与桌面小工具，强化 16 城地标。

- 精雕重建北京祈年殿、深圳平安中心、厦门双子塔、苏州东方之门、南京紫峰与长沙 IFS 主体，增加曲线檐、瓦脊、幕墙和塔冠。其他地标增加砖缝、桥拱、楼阁构件、座舱、广州塔钢架、东方明珠网格、五月的风钢带边缘。
- 静态几何按材质合并，树冠保留风力动画；本机精雕绘制调用约 168–542 次降到 88–96 次，不代表所有设备帧率保证。
- Plus 便利贴和倒数日各 8 条，独立可拖动面板，三种纸张、本机保存、复制、JSON 备份。倒数日是日历日期，不是闹钟。
- 苔庭、海盐、樱信、星夜四套皮肤；收藏地点、分城市历史、7 天记录、CSV、出行提示和可选系统提示。
- ¥1 / 7 天体验、¥5 / 当前设备永久，人工核款签发、离线签名校验。到期保留免费功能和笔记，购买入口未配置。
- GitHub OTA 清单签名、下载哈希核验，由用户选择安装重启。
- 保留后台托盘、无任务栏、桌面无工具条、物理坐标拖动；修复精雕切换时天气牌合成。

验证：36 项单元测试、43 项打包集成检查和 GitHub CI 通过；覆盖实际签名表单、两档 16 地标、15 天气、四皮肤、便利贴/倒数日、拖动及任务栏排除。真实 GitHub OTA 下载与签名/哈希校验通过，未执行系统安装。[详细结果](https://github.com/Sunnymark7/qihou-desktop/blob/main/docs/verification-0.4.0.md)。

边界：无自动支付发码，未购买商用天气、空气、地理编码套餐，收款运营前需确定服务授权。空气单源、壁纸实验性；未覆盖全部系统、显卡、混合 DPI、长期运行与实际系统安装升级。安装器没有 Windows 代码签名。
